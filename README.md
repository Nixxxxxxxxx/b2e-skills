# B2E Skills

11 скиллов для ИИ: исследовать проблему, спроектировать интерфейс, проверить решение и подготовить его к разработке

Это готовые инструкции для работы над продуктовыми задачами. Они задают порядок работы: изучить факты, уточнить то, что влияет на решение, сравнить варианты и подготовить конкретный результат. Если контекста достаточно, повторная анкета не нужна

Скиллы работают независимо друг от друга и не привязаны к продукту B2E

**Предварительный выпуск 2.0.0** · [Скачать набор ZIP](https://github.com/Nixxxxxxxxx/b2e-skills/releases/download/v2.0.0/b2e-skills.zip) · [Все загрузки](https://github.com/Nixxxxxxxxx/b2e-skills/releases/tag/v2.0.0)

## С чего начать

- **Работаете в Codex?** Установите папку нужного скилла целиком и вызовите его по имени
- **Работаете в обычном чате с ИИ?** Прикрепите полную MD-версию нужной категории и опишите задачу
- **Хотите весь набор?** В релизе есть общий ZIP с 11 скиллами, а также отдельные ZIP для каждого скилла и пяти категорий

Для одной задачи не нужно подключать всю библиотеку

## Как подключить

### В Codex

1. Скачайте нужный скилл из [релиза](https://github.com/Nixxxxxxxxx/b2e-skills/releases/tag/v2.0.0) или возьмите его папку из `skills/`
2. Поместите папку целиком в `.agents/skills/` своего проекта, сохранив `SKILL.md` и `references/` внутри
3. Начните новую сессию Codex и укажите имя скилла в запросе

Например, для работы со сценариями структура должна быть такой:

```text
your-project/
└── .agents/skills/
    └── b2e-design-user-flows/
        ├── SKILL.md
        └── references/
```

Первый запрос:

```text
$b2e-design-user-flows

Помоги проработать передачу заявки между оператором и руководителем.
Оператор создает заявку, руководитель принимает или возвращает ее.
Сейчас при возврате теряется причина. Вот текущие экраны и правила.
Сначала разбери контекст. Ничего не меняй в коде.
```

Codex также может выбрать скилл по описанию задачи без вызова по имени. У нас проверен один такой сценарий, не все 11; явный вызов позволяет указать нужный скилл. [Документация Codex](https://developers.openai.com/codex/skills/)

### В обычном чате с ИИ

Скачайте одну из пяти полных MD-версий категории, прикрепите файл и напишите: «Используй приложенную инструкцию для этой задачи», затем дайте задачу и доступные материалы

В полной MD-версии уже собраны инструкции и подробные методы. Один `SKILL.md` из репозитория не заменяет ее: он использует соседнюю папку `references/`

### В других инструментах

Пакеты используют формат [Agent Skills](https://agentskills.io/specification). Устанавливайте папку целиком по правилам своего клиента. Работа в других клиентах пока не проверена
