# B2E Skills

11 самостоятельных помощников для продуктового дизайна в пяти категориях. Сначала изучают доступный контекст, уточняют важное и помогают получить конкретный рабочий результат. Они не обещают сделать любую модель умнее или заменить исследование с людьми.

| Категория | Скиллы |
| --- | --- |
| Исследования | [План](skills/b2e-plan-product-research/SKILL.md) · [Интервью](skills/b2e-prepare-user-interviews/SKILL.md) · [Синтез](skills/b2e-synthesize-research/SKILL.md) |
| Проектирование интерфейсов | [Сценарии и состояния](skills/b2e-design-user-flows/SKILL.md) · [B2B-интерфейсы](skills/b2e-design-b2b-interfaces/SKILL.md) |
| Тестирование | [Подготовка теста](skills/b2e-plan-usability-tests/SKILL.md) · [Анализ наблюдений](skills/b2e-analyze-usability-tests/SKILL.md) |
| Визуал и референсы | [Дизайн-ревью](skills/b2e-review-product-design/SKILL.md) · [Направление по референсам](skills/b2e-design-with-references/SKILL.md) |

Например: «Проработай массовое назначение заявок. Есть частичные ошибки и разные права»; «Разбери записи теста: где человек справился сам, где помог модератор»; «Разложи мои референсы на приёмы, сохрани нашу дизайн-систему». Примеры по каждому скиллу — в [каталоге](catalog.json).

## Подключение

**Codex, на уровне проекта.** Скопируйте нужную папку целиком из `skills/` в `.agents/skills/` своего проекта. Сохраните `references/` рядом с `SKILL.md`. Начните новую сессию и укажите, например, `$b2e-design-user-flows`. Также возможен выбор по подходящему запросу; он зависит от инструмента и модели. [Документация Codex](https://developers.openai.com/codex/skills/).

**Другие инструменты с Agent Skills.** Используйте целую папку по правилам установки вашего клиента. Формат соответствует [Agent Skills](https://agentskills.io/specification), но поддержку и автоматический выбор конкретным клиентом нельзя вывести из формата. Текущий статус проверок — в [VALIDATION.md](VALIDATION.md).

**Обычный чат с ИИ.** Прикрепите полную MD-версию категории из релиза, затем сформулируйте задачу и дайте доступный контекст. В этих файлах уже включены подробности; не нужно прикреплять все 11 скиллов. Один `SKILL.md` без его references не равен полному пакету.

Скачивание: [релизы](https://github.com/Nixxxxxxxxx/b2e-skills/releases). Выпуск 2.0.0 подготовлен как предварительный и требует review до публикации. В релизе предусмотрены отдельные скиллы, ZIP категорий, общий ZIP и пять полных MD. Архивы 1.0.5 сохранены только для совместимости; они не входят в новый набор из 11 скиллов.

## Как устроено

Основной источник — `skills/` и `catalog.json`. Длинные подробности лежат в references и читаются по необходимости. Скиллы не требуют установки друг друга. Полные MD и ZIP собираются автоматически; их не редактируют вручную.

Для локальной сборки нужны Node.js 22+ и команды `zip`/`unzip`. Зависимостей npm нет.

```sh
npm test
npm run validate
npm run build
```

Сборка требует новый выходной каталог, чтобы не смешать релизы. Для повторной проверки используйте `node scripts/build.mjs /absolute/path/to/new-output`.

## Границы

Это инструкции для работы с предоставленными данными, а не база фактов о вашем продукте. Если контекста не хватает, помощник должен уточнить его или предложить проверку. Ревью не разрешает менять код; план исследования не означает проведённое исследование. Внешний поиск и действия в системах требуют соответствующего разрешения.

Условия использования — [USAGE.md](USAGE.md). Как предложить правку — [CONTRIBUTING.md](CONTRIBUTING.md). Не отправляйте закрытые записи, NDA-материалы и персональные данные в issues или PR.
